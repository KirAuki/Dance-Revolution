## Что доступно в админке

«Настройки сайта» → «SEO и поиск»:

- **Title главной страницы** — можно написать свой текст. `{dates}` автоматически подставляет диапазон дат, `{city}` — город, `{venue}` — площадку, `{year}` — год.
- **Description** — отдельное описание для поисковиков с теми же подстановками.
- **Изображение при отправке ссылки** — используется в Open Graph; для публикации с собственной обложкой приоритет имеет обложка статьи.
- **Коды подтверждения Google/Яндекса** — только значение `content` из метатега проверки владения. Эти поля не подключают аналитику и не устанавливают cookies.

Исходный `index.html` теперь содержит нейтральный запасной title без даты. Рабочий title и description формируются сервером из сохранённых настроек при каждом запросе. Ручная правка `index.html` для изменения даты не нужна.

## Действия после загрузки обновления

1. В ispmanager: «Сайты» → `dancesrevolution.ru` → редактирование → включить перенаправление HTTP в HTTPS. Проверить отсутствие циклических переходов и сохранение пути/параметров URL. Не добавлять наугад правила для X-Forwarded-Proto: схема проксирования зависит от хостинга.
2. Подтвердить сайт в Google Search Console и Яндекс Вебмастере. Для проверки через метатег использовать поля админки. При выборе DNS-проверки TXT-запись добавляется у DNS-провайдера.
3. Отправить `https://dancesrevolution.ru/sitemap.xml` в обе панели и запросить переобход главной и важных статей. После обхода проверить фактическую индексацию и выбранный canonical.
4. Проверить разметку события инструментом Google Rich Results Test. Время начала, билеты, отзывы и оценки не добавлялись, поскольку таких подтверждённых данных нет. Наличие разметки не гарантирует расширенный результат.
5. Подготовить оптимизированное hero-видео: короткий цикл, без звука, MP4/H.264 с fast start, подходящими разрешением и битрейтом; визуально сравнить с оригиналом. Затем измерить мобильную скорость в PageSpeed Insights. В рамках этой проверки измерения Lighthouse и полевые Core Web Vitals не выполнялись; числовой балл скорости не заявляется.
6. Публиковать полезные самостоятельные материалы: условия участия коллективов, номинации и критерии, подготовка заявки, программа 2–5 апреля, площадка и проживание. Каждой статье дать конкретный заголовок и описание. Не создавать страницы с повторяющимися списками ключевых слов.

Рабочие поисковые темы соответствуют содержанию: «хореографический конкурс Москва апрель 2027», «Танцевальная революция 2027», «конкурс танцевальных коллективов Москва», «танцевальный конкурс Останкино». Они должны естественно встречаться в полезном тексте, а не повторяться ради количества.

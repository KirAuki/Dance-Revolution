# Обновление SEO, документов и социальных ссылок

Архив предназначен для уже работающего сайта dancesrevolution.ru. Включает предыдущие изменения страницы cookies, поэтому отдельно загружать старый архив cookies не требуется. В архиве нет `.env`, базы, пользовательских файлов, фотографий или видео.

## Установка

1. Сделайте резервную копию папок `backend/`, `shared/`, `dist/` в `/var/www/u3717756/data/dance-revolution/`. Закройте открытые редакторы в админке до завершения обновления.
2. Сначала скопируйте содержимое `public/bundles/` в `/var/www/u3717756/data/www/dancesrevolution.ru/bundles/`. Старые файлы с другими именами пока оставьте для открытых вкладок.
3. Скопируйте содержимое `application/` в `/var/www/u3717756/data/dance-revolution/`, объединяя папки и заменяя одноимённые файлы. Новые шаблоны должны оказаться в `dance-revolution/backend/templates/`.
4. Удалите только два старых файла иконок, если они есть:
   - `/var/www/u3717756/data/www/dancesrevolution.ru/assets/social/instagram.svg`
   - `/var/www/u3717756/data/www/dancesrevolution.ru/assets/social/whatsapp.svg`
5. Перезапустите приложение:

```sh
touch /var/www/u3717756/data/www/dancesrevolution.ru/.restart-app
```

Вместо команды можно создать пустой файл `.restart-app` в указанной публичной папке через файловый менеджер. REG.RU удалит его после перезапуска.

Обновление базы и зависимостей не требуется. `.env`, SMTP, cron, статьи, заявки и пароли остаются в существующей установке. Старые поля удалённых соцсетей автоматически исключаются при чтении настроек; при следующем сохранении настроек они исчезнут из текущей записи в базе. Архив не заменяет серверный `.htaccess`, чтобы не затронуть ваши правила хостинга.

## После установки

- Обновите страницу админки. В «Настройки сайта» → «Даты и город» проверьте: заезд **02.04.2027**, начало **03.04.2027**, финал **04.04.2027**, выезд **05.04.2027**. При проверке опубликованного сайта эти даты уже стояли правильно.
- В «SEO и поиск» можно изменить title, description, изображение для ссылок и коды проверки поисковых панелей. Поля с `{dates}`, `{city}`, `{venue}`, `{year}` обновляются из настроек автоматически.
- Откройте исходный HTML главной: title, description, H1, основные тексты и JSON-LD должны присутствовать до выполнения JavaScript.
- Проверьте отсутствие Instagram/WhatsApp в футере; остаются Telegram, VK и MAX.
- Проверьте `/cookies`, `/news`, `/sitemap.xml` и редирект `/index.html` на `/`.
- Включите HTTP → HTTPS в ispmanager. После этого `http://dancesrevolution.ru/` должен перенаправлять на `https://dancesrevolution.ru/`.

Подробный отчёт о проверке, оставшиеся задачи и официальные источники находятся в `SEO-AUDIT.md` внутри архива.
